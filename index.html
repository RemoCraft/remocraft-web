Who are we?

RemoCraft was born to provide a deep, respectful Survival RPG experience. We aim to build a community where players progress through skills, found powerful nations and explore a handcrafted map full of secrets and dungeons. Here, your experience is not just a level — it's the mana powering your abilities.

Is the server premium?

Yes — the server currently requires a Minecraft Java (premium) account to join.

Is Bedrock supported?

No — at the moment we only support Minecraft Java Edition (premium accounts).

Is the server pay-to-win?

No — we don't design pay-to-win mechanics. If you think a feature is pay-to-win, please report it and we'll review it.
